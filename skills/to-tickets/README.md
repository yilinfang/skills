# to-tickets

Split a plan, spec, or conversation into self-contained tracer-bullet tickets under .tickets/<feature-slug>/, one file per ticket, for fresh sessions to implement one at a time

## Source

Adapted from [mattpocock/skills](https://github.com/mattpocock/skills/blob/main/skills/engineering/to-tickets/SKILL.md). Tracker integration and setup dependencies removed; tickets are written as local files only.
