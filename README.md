# skills

A collection of skills created by me or collected from the internet. The skills include native Codex metadata and remain compatible with Claude Code.

## Installation

```
npx skills@latest add yilinfang/skills
```

or

```
bunx skills@latest add yilinfang/skills
```

## Local testing

To test changes without pushing, install from a local clone:

```
cd /path/to/skills
bunx skills@latest add .
```

Re-run after each change. To test a single skill, pass its path, e.g. `bunx skills@latest add ./in-progress/to-tickets`.
