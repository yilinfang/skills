# skills

Skills installed by users with `npx skills add yilinfang/skills`. Every file under `skills/<name>/` ships to every installer, so a skill folder holds only what a user's agent needs: `SKILL.md`, its reference files, and a `README.md`. Maintainer guidance lives here and in each skill's README.

## Editing a skill

1. Load the `writing-for-agents` skill before you edit a `SKILL.md`.
2. Read the skill's `README.md` first. Its Decisions section records why the skill is shaped the way it is. A change that reverses a decision needs the user's approval before you make it.
3. `SKILL.md` is the source of truth. After you edit it, update the README summary so the two agree.
4. Record a settled design change as one line in the README's Decisions section.
